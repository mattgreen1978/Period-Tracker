FAMILY CYCLE TRACKER — FREE WEB APP

Files: index.html, manifest.webmanifest, icon.svg, sw.js.

To publish for free with GitHub Pages:
1. Create a GitHub account and a new repository (GitHub Pages on the free plan typically requires a PUBLIC repository).
2. Upload these four files to the repository root. Do NOT upload backups or CSV files.
3. Under Settings > Pages, choose Deploy from a branch, main, /(root), and save.
4. Open the resulting https://USERNAME.github.io/REPOSITORY/ address on iPhone Safari.
5. Tap Share > Add to Home Screen.

Privacy: GitHub Pages hosts only the app code. Your health records are stored in the browser on your iPhone, not in GitHub. The app has no login, encryption or Face ID. Make encrypted device backups and protect access to your phone. JSON exports and CSV files are unencrypted and should be stored securely.

Do not rely on predictions for contraception or medical decisions. Irregular cycles are common in teenagers and perimenopause.

Updating: upload changed app files to the same GitHub repository. Back up records first. Preserve the local storage key and data format, or implement migration, to avoid losing records.
